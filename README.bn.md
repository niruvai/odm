## কেন ODM?

Windows-এ সবার জন্য আছে IDM। macOS-এ ব্রাউজার একটা ফাইল একটাই কানেকশনে নামায়, আর নেট কেটে গেলে অনেক সময় আবার শুরু থেকে নামাতে হয়। **ODM** প্রতিটা ফাইলকে কয়েক ভাগে ভাগ করে একসাথে নামায়, আর থেমে গেলে ঠিক যেখানে ছিল সেখান থেকেই আবার শুরু করে। ইন্টারফেসটা ম্যাকের নিজস্ব SwiftUI দিয়ে বানানো।

| 🗂️ | **গোছানো ফোল্ডার** | Video, Music, Compressed, Programs, Documents, Images আলাদা আলাদা |

| 💤 | **ম্যাক-বান্ধব** | মেনু বারে আইকন, Dock-এ সংখ্যা, আর ডাউনলোডের সময় ম্যাক ঘুমায় না |

## যা লাগবে

- macOS 13 Ventura বা নতুন
- Apple Silicon বা Intel ম্যাক
- ভিডিও ডাউনলোডের অংশগুলোর জন্য প্রায় ১৫০ MB জায়গা (প্রথমবার চালুর সময় একবারই ইনস্টল হয়)

## ইনস্টল

1. সর্বশেষ রিলিজ থেকে **[ODM.zip](https://github.com/niruvai/odm/releases/latest)** নামান।
2. জিপ খুলে **ODM.app** টেনে **Applications** ফোল্ডারে রাখুন।
3. ODM খুলুন। ODM Apple-এর notarization করা নয়, তাই প্রথমবার macOS আটকাতে পারে: **System Settings → Privacy & Security**-এ গিয়ে নিচে **Open Anyway** চাপুন।

প্রথমবার চালু হলে ODM একটা **সেটআপ স্ক্রিন** দেখায়, যেখানে ভিডিও ডাউনলোডের দরকারি অংশগুলো নামে আর প্রতিটার অগ্রগতি দেখা যায়। শেষ হলে একটা **ধাপে ধাপে গাইড** Chrome এক্সটেনশন যুক্ত করতে সাহায্য করে।

### Chrome এক্সটেনশন

গাইডটা সব দেখিয়ে দেয়, আর পরে **Settings → Browser → Open Setup Guide…** থেকে আবার খোলা যায়।

1. Chrome-এ `chrome://extensions` খুলুন (Edge আর Brave-এও একই নিয়ম)।
2. ডানদিকে উপরে **Developer mode** চালু করুন।
3. **Load unpacked** চেপে `~/Library/Application Support/ODM/ChromeExtension` ফোল্ডারটা বেছে নিন — অথবা ফোল্ডারটা টেনে এক্সটেনশন পেজে ছেড়ে দিন।

এক্সটেনশন যুক্ত হলে গাইডে সবুজ ✓ দেখায়। ODM আপডেট হওয়ার পর `chrome://extensions`-এ ODM এক্সটেনশনের **↻ Reload** চাপুন।

> **টিপ:** Chrome-এর **Settings → Downloads**-এ *“Ask where to save each file before downloading”* বন্ধ রাখুন।

## ব্যবহার

| কাজ | কীভাবে |
|---|---|
| নতুন ডাউনলোড | **⌘N** চাপুন — কপি করা লিংক নিজে বসে যায়; একসাথে অনেক লিংক, এক লাইনে একটা করে |
| Chrome থেকে | স্বাভাবিকভাবে ডাউনলোড করুন, ODM নিজেই ধরে নেবে |
| ভিডিও ডাউনলোড | ভিডিওর নিচে **ODM** বা প্লেয়ারের উপর **Download** চেপে কোয়ালিটি বেছে নিন |
| অন্য ভিডিও সাইট | এক্সটেনশনের আইকন → **Download video**, অথবা পেজে রাইট-ক্লিক → **Download video with ODM** |
| থামানো / চালু | টুলবারের বাটন, রাইট-ক্লিক, বা প্রোগ্রেস উইন্ডো |
| সব থামানো / সব চালু | **⇧⌘P** / **⇧⌘R** |
| ফাইল খোলা | তালিকায় ডাবল-ক্লিক, বা প্রোগ্রেস উইন্ডোর **Open Folder** |
| সেটিংস | **⌘,** |

ফাইল সেভ হয় `~/Downloads/ODM/<ধরন>/`-এ। ডাউনলোড ফোল্ডার, কানেকশনের সংখ্যা, একসাথে কয়টা ডাউনলোড আর ভিডিওর কোয়ালিটি Settings থেকে বদলানো যায়।

> **দায়িত্বের সাথে ব্যবহার করুন।** শুধু সেই ভিডিও নামান যেগুলো সেভ করার অধিকার আপনার আছে — নিজের আপলোড, Creative Commons, বা মালিকের অনুমতি নিয়ে — আর প্রতিটা সাইটের নিয়ম মেনে চলুন।

## আপডেট

ODM চালু হওয়ার সময় আর প্রতি ৬ ঘণ্টায় নতুন ভার্সন খোঁজে। নতুন ভার্সন এলে উইন্ডোর উপরে ব্যানার আসে — **Update Now** চাপলে ODM নিজেই ইনস্টল করে আবার চালু হয়, আর অসমাপ্ত ডাউনলোড যেখানে ছিল সেখান থেকে চলতে থাকে। নিজে চেক করতে: **ODM → Check for Updates…**

## সমস্যা হলে

<details>
<summary><b>সেটআপ স্ক্রিন থেমে যায় বা এরর দেখায়</b></summary>

ইন্টারনেট সংযোগ দেখে **Try Again** চাপুন। অংশগুলো GitHub আর FFmpeg-এর সার্ভার থেকে নামে; কোনো ফায়ারওয়াল বা VPN সেগুলো আটকালে সেটআপ শেষ হবে না।
</details>

<details>
<summary><b>ভিডিওতে “Sign in to confirm you're not a bot” বা “HTTP 403” দেখায়</b></summary>

**Settings → Video → Use my browser sign-in** চালু করুন, তারপর পেজের ODM বাটন দিয়ে ভিডিওটা আবার পাঠান। এক্সটেনশন আপনার লগইন ODM-কে দিয়ে দেয়।
</details>

<details>
<summary><b>YouTube-এ ODM বাটন দেখা যাচ্ছে না</b></summary>

পেজ রিফ্রেশ করুন (**⌘R**)। তারপরও না এলে `chrome://extensions`-এ এক্সটেনশনটা চালু আছে কিনা দেখুন।
</details>

<details>
<summary><b>এক্সটেনশন বলছে “ODM app is not running”</b></summary>

ODM অ্যাপটা খুলুন। উইন্ডো বন্ধ করলেও ODM মেনু বারে চলতে থাকে।
</details>

<details>
<summary><b>যেসব সীমাবদ্ধতা আছে</b></summary>

- যে সার্ভার byte range সমর্থন করে না, সেখানে একটাই কানেকশন চলে আর Resume হয় না।
- POST ফর্ম দিয়ে শুরু হওয়া কিছু ডাউনলোড ODM-এ পাঠানো যায় না।
- প্রাইভেট বা মেম্বারশিপ ভিডিও নামানো যায় না।
- ODM শুধু macOS-এ চলে।
</details>

## গোপনীয়তা

ODM-এ কোনো অ্যাকাউন্ট, অ্যানালিটিক্স বা ট্র্যাকিং নেই। ব্রাউজার এক্সটেনশন শুধু আপনার নিজের ম্যাকের ODM অ্যাপের সাথে কথা বলে (`127.0.0.1`)। ভিডিও ডাউনলোডে ব্যবহৃত সাইটের লগইন কুকি আপনার ম্যাকেই একটা ব্যক্তিগত ফাইলে থাকে, যা শুধু আপনার ইউজার অ্যাকাউন্ট পড়তে পারে। ODM ইন্টারনেটে যায় শুধু আপনার ফাইল নামাতে, ভিডিওর অংশগুলো ইনস্টল ও আপডেট করতে, আর GitHub-এ নতুন ভার্সন খুঁজতে।

## সোর্স থেকে বিল্ড

Apple-এর Command Line Tools লাগবে (`xcode-select --install`); পুরো Xcode লাগবে না।

```bash
git clone https://github.com/niruvai/odm.git
cd odm
./build.sh --install    # ODM.app বানিয়ে /Applications-এ বসায়
```

`main`-এ প্রতিটা পুশ [GitHub Actions](.github/workflows/release.yml) দিয়ে বিল্ড হয়ে রিলিজ হিসেবে প্রকাশ হয়; অ্যাপের আপডেট সেখান থেকেই আসে। কোডের বিস্তারিত গঠন [ইংরেজি README](README.md#building-from-source)-তে আছে।
